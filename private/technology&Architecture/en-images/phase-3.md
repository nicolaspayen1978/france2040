# Phase 3 — Reproducible figure data (optional)

Status: not started. Optional. Does not unlock comments on visuals.

## Entry

Phase 1 library exists. A visual’s numbers are repeatedly questioned, or a second version of a simulation chart is needed and hand-drawing from Excel is error-prone.

## Slice

1. Optional data companion per visual version (CSV or frozen table in content), hashed like the figure.
2. Page section **Données** listing the series, units, and the model or source version they came from.
3. Still no write-back from the live spreadsheet at build time unless that spreadsheet version is itself a published, hashed attachment on the model document.

## Exit

A sceptical reader can see the numbers behind at least one simulation chart without downloading an unpublished file.

## Not in this phase

Comment store on visuals. Accounts. Chart JS interactivity as a substitute for provenance.
